# Security Policy

## Supported Versions

Only the [latest release](https://github.com/cacack/roulette-wheel/releases/latest) receives security fixes.

| Version        | Supported |
|----------------|-----------|
| Latest release | Yes       |
| Older releases | No        |

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue.

This is a hobby project, so responses are best-effort. You should get an acknowledgement within a couple of weeks.

## Scope

Roulette Wheel is an offline desktop application with no network services. The most relevant reports are about the release binaries, the build and CI pipeline, and dependencies.
